# `<dw-date-select>` [![Published on npm](https://img.shields.io/npm/v/@dreamworld/dw-date-select.svg)](https://www.npmjs.com/package/@dreamworld/dw-date-select)

Date select is used to select custom date

## Behaviour

- It extends [`dw-select`](https://github.com/DreamworldSolutions/dw-select), so It overrides all the beahviors of `dw-select` input control

### Usage

```html
<dw-date-select items="${this.items}" label="outlined" mobileMode=${true} .value=${this.value}></dw-date-select>
```
